LiveMock 教程 - 5 分钟 ⏱️

上手即用

自托管 dashboard，几分钟就能上手。按 method、path、header、query 和请求体匹配请求，并用分组设置各自的优先级(priority)。可以用 Docker 运行，也可以从源码运行。

动态 mock

修改 API 响应立即生效，无需重启服务。可以返回自定义 JSON 或 Mock.js 模板，proxy 到真实后端（含 WebSocket），或从磁盘目录提供文件。

日志与分析

每个请求都会被记录。可以用预设或自定义 JSON 路径筛选，选择需要的列，查看 WebSocket 消息，还能一键把捕获的请求变成 mock。
