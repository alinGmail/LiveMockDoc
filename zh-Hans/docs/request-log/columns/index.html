列

详情旁边的列表可以为每个请求显示更多或更少的字段。打开筛选栏右侧的 Columns 菜单。

行字段​

每一行可以额外开启三个字段：

字段显示内容
Expectation命中的 expectation 名称。
Duration响应的耗时，单位毫秒。
Proxy / WS markerPROXY / WS 徽章。

method、path、时间和状态码始终显示。选择会按项目记住。

显示与隐藏​

每个行字段都可以在同一个菜单里开关，因此可以把列表调成你需要的精确样子——例如排查超时时，只显示命中的 expectation 和耗时。

备注

早期版本的 LiveMock 允许用任意 JSON 路径和文本/JSON 显示类型定义额外的列。当前 dashboard 只提供上面三个行字段；请求记录本身仍然记录所有内容，详情面板会显示完整的请求和响应，因此某个字段不作为列显示也不会丢失任何信息。

参见​

  • 筛选器 —— 用 JSON 路径缩小列表范围，这是查看日志任意字段的方式。
