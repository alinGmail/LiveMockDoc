# 👤 设置

账号名旁边的齿轮图标会打开账号设置页面。

![设置](/img/screenshots/21-settings.png)

## 账号

页面显示拥有当前实例的账号。LiveMock 只支持一个账号——参见[认证](./auth.md)。

## 修改密码

输入当前密码，然后把新密码输入两次。新密码至少 8 个字符。修改密码会**让其他所有会话登出**：只有你执行修改的那台设备保持登录。

## API 令牌 {#api-tokens}

**API tokens** 卡片用于为 [MCP server](./mcp.md)创建令牌。给每个客户端分配自己的令牌，并选择有效期，或保持 **Never**。

- 令牌只显示**一次**；LiveMock 只保存它的哈希。
- 令牌拥有数据面的完整权限：项目、expectation、分组、请求记录和导入。
- 令牌不能创建或吊销其他令牌，也不能修改密码。这些操作需要浏览器会话。
- 停用某个客户端时，就在同一张卡片上吊销它的令牌。

修改账号密码或运行 `livemock reset-admin` 会吊销所有令牌。

## 版本

页面底部显示正在运行的服务版本。在反馈问题，或确认某次部署是否生效时很有用。

## 项目设置

项目设置不在这里：点击应用栏里的齿轮（项目切换器旁边）来编辑当前项目。参见[项目](./project.md)。
