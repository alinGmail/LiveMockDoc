# 筛选器(filter)

请求列表上方的筛选栏用于缩小显示范围。筛选器**按项目保存**，下次打开页面时会恢复。

![筛选后的请求记录](/img/screenshots/12-request-log-filtered.png)

## 预设筛选器

筛选栏中的按钮用于切换最常用的筛选器：

| 按钮 | 保留的请求… |
| --- | --- |
| `GET`、`POST`、`PUT`、`DELETE` | …method 为选中项。可以同时启用多个。 |
| `2xx`、`3xx`、`4xx`、`5xx` | …状态码属于选中的状态族。可以同时启用多个。 |

左侧的下拉框（默认 **All requests**）用于选择按哪条 expectation 筛选。

## 自定义筛选器

点击 **+ Add filter**，针对日志对象的任意字段添加筛选器：

![自定义筛选器编辑器](/img/screenshots/13-custom-filter.png)

| 字段 | 含义 |
| --- | --- |
| **Property** | 指向日志对象的 JSON 路径，例如 `req.path`、`req.method`、`res.status`、`res.duration` 或 `req.headers.host`。 |
| **Condition** | 值的比较方式（见下文）。 |
| **Value** | 与什么比较。输入值后按 Enter；可以累积多个值。 |
| **Active** | 保留筛选器定义，但暂时关闭它。 |

自定义筛选器在筛选栏中显示为标签。点击标签可以编辑，点击小叉号可以删除。

## 条件

| 条件 | 保留值… |
| --- | --- |
| `EQUAL` | …等于给定值的请求（数字形式和字符串形式都算）。 |
| `NOT_EQUAL` | …不等于给定值的请求。 |
| `CONTAINS` | …包含给定值的请求。 |
| `GREATER` | …大于给定值的请求。 |
| `LESS` | …小于给定值的请求。 |
| `IN` | …属于所列值之一的请求。 |
| `FAMILY` | …匹配 `2xx` 这类状态族标记的请求，该标记会展开为一个闭区间。 |

## 组合筛选器

所有启用的筛选器必须同时成立：预设筛选器和自定义筛选器会组合在一起。结果为空时列表会明确提示——移除或关闭某个筛选器就能看到更多请求。

## 清除筛选器

用左侧下拉框回到 **All requests**，关闭预设按钮并移除自定义标签。右侧的 **Clear** 按钮是另一回事：它删除已捕获的请求，而不是清除筛选器。
