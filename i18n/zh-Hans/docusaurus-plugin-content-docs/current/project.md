# 📁 项目

一个项目(project)就是一个 mock server：独立的端口、独立的 expectation、独立的请求记录。你可以同时运行多个项目，各自使用不同端口，并在应用栏里切换。

## 创建项目

第一个项目在欢迎页创建。后续项目通过应用栏里的项目切换器创建：打开菜单并选择 **New project**。表单会询问：

| 字段 | 含义 |
| --- | --- |
| **项目名** | 显示在切换器中。 |
| **端口** | mock server 监听的端口。默认 `8088`。 |
| **Max request log** | 项目保留多少条请求记录。最小 `1000`，默认 `5000`。 |
| **描述** | 可选的自定义文本。 |

## 项目设置

应用栏里的齿轮会打开当前项目的设置。

![项目设置](/img/screenshots/20-project-settings.png)

- **项目名**和**描述**随时可以修改。
- **端口**只能在项目停止时修改。
- **Max request log** 是请求记录的上限。最旧的条目会被自动裁剪（大约每分钟执行一次），因此繁忙的项目也不会无限增长。
- **Delete project** 会删除项目及其全部 mock 数据。你必须输入项目名来确认，并且项目必须处于停止状态。

## 运行状态

应用栏显示当前项目及其状态：

| 状态 | 含义 |
| --- | --- |
| `stopped :8088` | mock 端口已关闭。 |
| `running :8088` | mock 端口接受请求。 |
| `starting :8088`、`stopping :8088` | 过渡状态，稍等片刻。 |

旁边的圆形按钮用于启动和停止项目。项目运行期间也可以编辑 expectation——没有任何需要重启的东西。

:::info[切换项目]

在应用栏切换项目只会改变 dashboard 中显示的 expectation 和请求记录，不会启动或停止任何东西：项目会独立地保持运行（或保持停止）。

:::

## 删除项目

删除不可撤销，会连同项目本身一起删除它的 expectation、分组、筛选器和请求记录。
